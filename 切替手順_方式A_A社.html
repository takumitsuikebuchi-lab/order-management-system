A社 切替手順メモ

このファイルは、旧来の「各PCで個別に Supabase を設定する」方式A資料を、現行運用に合わせて整理したメモです。

現在の標準運用では、各PCでクラウド設定を手入力しません。cloud-config.json を更新して GitHub Pages に反映するのが正規手順です。

現行の切替手順

  1. 切替先の Supabase プロジェクトを用意する
  2. cloud-config.json の URL / anon key / enabled を更新する
  3. main に commit / push する
  4. GitHub Pages 反映後、各端末でハードリロードする
  5. 右上が 接続: Cloud（同期完了） になることを確認する

データ移行が必要な場合

  • 先に CSV バックアップを取得する
  • 新しい Supabase 側へ受注データとマスターを投入する
  • その後で cloud-config.json を切り替える

やってはいけないこと

  • 通常URLの画面から各PCごとにバラバラのクラウド設定を保存する
  • 本番設定を変更したのに cloud-config.json を更新しない
  • 切替後の確認をせず、そのまま業務を再開する

補足

緊急診断時だけ ?manualCloudConfig=1 を使って一時的に手動変更できますが、最終的な正本は必ず cloud-config.json に合わせてください。

詳細は SETUP.md と AGENTS.md を参照してください。
