受注管理システム 運用マニュアル

2026年3月時点の現行運用に合わせたマニュアルです。現在の本番公開先は GitHub Pages で、共通クラウド設定は cloud-config.json から自動適用されます。

本番URL: https://takumitsuikebuchi-lab.github.io/order-management-system/

日常運用

  1. 本番URLを開く
  2. 右上が 接続: Cloud（同期完了） になることを確認する
  3. そのまま受注登録、編集、複製、削除、マスター更新を行う

通常運用では、画面のクラウド設定を手で触る必要はありません。

ステータス表示の見方

表示意味
接続: Cloud（同期完了）正常。最新データに同期済み
接続: Cloud（同期中）起動直後や同期処理の途中
接続: Cloud（エラー）通信や接続設定に問題がある可能性
接続: ローカルクラウド設定が使われていない状態

マスター同期の仕様

  • 顧客、積荷、荷姿、単位、ドライバー、車両は Supabase と同期されます
  • 空配列も有効なデータとして同期されます
  • つまり、ある端末で全削除して保存すると、他端末でも空になります

同時編集について

同じ受注を複数端末で開いたまま編集すると、保存時に競合検知が働きます。

  • 別端末で先に更新されていれば、保存時に警告して停止します
  • 警告が出たら、いったん閉じて最新の受注を開き直してください

クラウド設定を変更したいとき

通常は画面から変更しません。正本は cloud-config.json です。
  1. cloud-config.json を編集する
  2. main に commit / push する
  3. GitHub Pages の反映を待つ
  4. ブラウザをハードリロードする

緊急診断だけは ?manualCloudConfig=1 付きURLで一時的に手動変更できます。

困ったとき

  • データ差異が出たら、まず右上表示を確認する
  • ハードリロード後も直らなければ SETUP.md を参照する
  • AIツールに依頼するときは AGENTS.md と SETUP.md を先に読ませる
