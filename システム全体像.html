受注管理システム 全体像

2026年3月時点の現行構成です。現在の本番公開先は GitHub Pages、共有クラウド設定は cloud-config.json、データ本体は Supabase を利用しています。

現行アーキテクチャ

利用者 ↓ GitHub Pages https://takumitsuikebuchi-lab.github.io/order-management-system/ ↓ index.html が cloud-config.json を読込 ↓ Supabase の orders / customers / simple_masters に接続 ↓ 取得した最新データを画面表示 ↓ ブラウザ localStorage にもキャッシュ・バックアップ保持

構成要素

GitHub Pages

静的ファイルの公開先です。通常の本番反映は main への push で行います。

cloud-config.json

Supabase の URL / anon key / enabled を配布する正本です。ブラウザごとの差異を防ぐ役割があります。

Supabase

受注、顧客マスタ、各種シンプルマスタの共有データベースです。

localStorage

ブラウザ側のキャッシュ兼バックアップです。日常運用の正本ではなく、補助的な位置づけです。

同期の考え方

  • 起動時にクラウドの最新データを取得して表示します
  • 受注やマスターの更新はクラウドに反映されます
  • 通信に失敗したときはキューに積み、復帰後に再送します
  • 空のマスター状態も有効データとして同期されます

安全性のための仕組み

  • 共有クラウド設定が有効なとき、通常画面からクラウド設定は編集できません
  • 緊急診断時だけ ?manualCloudConfig=1 で一時解除できます
  • 同じ受注を複数端末で編集していた場合は、保存前に競合警告を出します
